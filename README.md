## 📌 Featured Projects

### 📊 [Startup Funding Analysis](https://github.com/AndrewHung87/startup_funding_analysis)

**Tech:** Python · pandas · BigQuery SQL · Tableau Public · ETL · EDA

End-to-end startup funding analysis using a cleaned Crunchbase-style dataset of 1,576 companies.  
Built a Python cleaning workflow, BigQuery SQL analysis layer, exported SQL result tables, and a 4-view Tableau Public dashboard to analyze funding trends across industries, geographies, and time periods.

**Highlights:**
- Cleaned 1,827 raw records into a 1,576-record analysis dataset
- Built 6 BigQuery SQL business queries covering funding, geography, hiring signals, and industry rankings
- Identified a 79% increase in total funding and 139% growth in median deal size within the analyzed 2024-2025 dataset

### 🛡️ [SMSGuard](https://github.com/AndrewHung87/smsGuard)

**Tech:** Python · PostgreSQL · BigQuery · Scikit-learn · Streamlit · SQLAlchemy

End-to-end NLP spam detection pipeline using 10K+ SMS messages.  
Built an ETL workflow with validation, deduplication, PostgreSQL and BigQuery loading, then trained a TF-IDF + Naive Bayes classifier and visualized model performance in a Streamlit dashboard.

**Highlights:**
- Achieved 97% accuracy, 94% precision, and 93% recall
- Built a Streamlit dashboard with live prediction, ROC curve, confusion matrix, and classification metrics
- Structured the pipeline around ingestion, cleaning, storage, modeling, and reporting
